# Verbiya - Professional English Learning Platform

A modern, AI-enhanced personalized learning platform designed to empower non-native English speakers with domain-specific vocabulary and language skills necessary for professional and academic success.

## 🎯 Mission

Verbiya bridges the gap between conversational fluency and subject matter proficiency through an intuitive, AI-enhanced personalized learning platform. We help learners master industry-specific terminology and real-world applications in their chosen professional domains.

## ✨ Features

- **Personalized Learning**: Choose topics that match your professional needs
- **Flexible Schedule**: Learn at your own pace with custom time estimates
- **Expert Content**: Industry-specific vocabulary and real-world applications
- **Domain-Specific Paths**: Specialized learning tracks for different professional fields
- **Modern UI/UX**: Clean, intuitive interface designed for optimal learning experience

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd verbiya
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm run eject` - Ejects from Create React App (one-way operation)

## 🎨 Design System

The application uses a consistent design system with:

- **Primary Colors**: Green palette (#2E7D32, #4CAF50, #E8F5E8)
- **Typography**: Inter font family for optimal readability
- **Components**: Reusable UI components with consistent styling
- **Responsive Design**: Mobile-first approach with breakpoints at 768px and 480px

## 🌐 Available Domains

Currently supported professional domains:

1. **Biotechnology** - Genetic engineering, protein expression, cell culture
2. **Business English** - Financial analysis, contract negotiation, market research
3. **Chemistry** - Organic chemistry, analytical methods, lab equipment

## 🔧 Technology Stack

- **Frontend**: React 18 with TypeScript
- **Routing**: React Router DOM
- **Styling**: CSS with CSS Variables and Flexbox/Grid
- **Icons**: Lucide React
- **Build Tool**: Create React App
- **Package Manager**: npm

## 📱 Responsive Design

The application is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (480px - 767px)
- Small Mobile (< 480px)
